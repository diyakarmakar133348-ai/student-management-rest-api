
# 🎓 Student Management REST API

A simple Student Management REST API developed using **C# and ASP.NET Core .NET 8**. This project allows users to perform CRUD operations (Create, Read, Update, Delete) on student records using SQL Server.

## ✨ Features

- 📋 View all students
- 🔍 Search students by ID
- ➕ Add new student records
- ✏️ Update student details
- 🗑️ Delete student records
- 📚 Swagger UI for API testing
- 🗄️ SQL Server database integration
- ⚙️ Automatic database creation

## 🛠️ Technologies Used

- C#
- .NET 8
- ASP.NET Core Minimal API
- Entity Framework Core
- SQL Server
- Swagger / OpenAPI
- Visual Studio Code

## 📁 Project Structure

```text
StudentManagementAPI/

├── Program.cs
```

## 📌 Requirements

Before running this project, install:

1. .NET 8 SDK
2. Visual Studio Code
3. C# Dev Kit Extension
4. SQL Server Express
5. SQL Server Management Studio (Optional)

Check your .NET version:

```bash
dotnet --version
```

## 🚀 Installation and Setup

### Step 1: Create a New Project

Open the VS Code terminal and execute:

```bash
dotnet new web -n StudentManagementAPI
cd StudentManagementAPI
```

### Step 2: Install Required Packages

```bash
dotnet add package Microsoft.EntityFrameworkCore.SqlServer --version 8.0.0

dotnet add package Swashbuckle.AspNetCore --version 6.5.0
```

### Step 3: Add the Source Code

Open `Program.cs`, remove the existing code, and paste the complete Student Management API code.

### Step 4: Configure SQL Server

The default connection string is:

```text
Server=.\SQLEXPRESS;Database=StudentManagementDB;Trusted_Connection=True;TrustServerCertificate=True;
```

Make sure SQL Server Express is installed and running.

Change the server name in the code if your SQL Server instance is different.

### Step 5: Run the Application

```bash
dotnet restore
dotnet run
```

Open the localhost URL displayed in your terminal and add `/swagger`.

Example:

```text
https://localhost:7001/swagger
```

Use the actual port displayed in your terminal.

## 🌐 API Endpoints

| HTTP Method | Endpoint | Description |
|---|---|---|
| GET | `/api/students` | Get all students |
| GET | `/api/students/{id}` | Get student by ID |
| POST | `/api/students` | Add a new student |
| PUT | `/api/students/{id}` | Update student details |
| DELETE | `/api/students/{id}` | Delete a student |

## 🧪 Sample JSON Request

Use the following JSON for adding a new student through the POST endpoint:

```json
{
  "name": "Priyanshi",
  "email": "priyanshi@example.com",
  "age": 20,
  "course": "Computer Engineering"
}
```

The student ID is automatically generated by the database.

5. Enter the required information.
6. Click **Execute** to test the API.

## 📤 Upload Project to GitHub

### Step 1: Create a Repository

- Visit [GitHub](https://github.com/).
- Click on New Repository.
- Enter the name `StudentManagementAPI`.
- Select Public or Private.
- Click Create Repository.

### Step 2: Initialize Git

Open the terminal inside your project folder.

```bash
git init
git add .
git commit -m "Add Student Management REST API"
```

### Step 3: Set Main Branch

```bash
git branch -M main
```

### Step 4: Connect GitHub Repository

Replace `YOUR_USERNAME` with your GitHub username.

```bash
git remote add origin https://github.com/YOUR_USERNAME/StudentManagementAPI.git
```

### Step 5: Push to GitHub

```bash
git push -u origin main
```

Your project will now be available in your GitHub repository.
